===============================================
COIN COLLECTION TRACKER - DJANGO API
QUICK START GUIDE
===============================================

🚀 GET YOUR API RUNNING IN 5 MINUTES!

Step 1: Open Terminal
----------------------
cd C:\sites\Python\repos\coin-collection-inventory-tracker\backend


Step 2: Create Virtual Environment
-----------------------------------
python -m venv venv


Step 3: Activate Virtual Environment
-------------------------------------
Windows PowerShell:
    venv\Scripts\activate

Windows Command Prompt:
    venv\Scripts\activate.bat


Step 4: Install Dependencies
-----------------------------
pip install -r requirements.txt

(Takes 1-2 minutes)


Step 5: Create .env File (Optional)
------------------------------------
Django will read database credentials from your root .env file!
Optionally create backend/.env with Django-only settings:

SECRET_KEY=my-secret-key-for-django
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

(Database credentials come from root .env automatically!)


Step 6: Run Migrations
-----------------------
python manage.py migrate


Step 7: Create Admin User
--------------------------
python manage.py createsuperuser

Username: admin
Password: (your choice)


Step 8: Start Server
---------------------
python manage.py runserver


Step 9: Test in Browser
------------------------
Open these URLs:

http://localhost:8000/api/
http://localhost:8000/api/coins/
http://localhost:8000/api/stats/
http://localhost:8000/admin/


===============================================

===============================================
TROUBLESHOOTING
===============================================

Problem: Can't connect to database
Fix: Check .env file has correct credentials

Problem: Port 8000 in use
Fix: python manage.py runserver 8080

Problem: Module not found
Fix: Make sure venv is activated (see Step 3)
